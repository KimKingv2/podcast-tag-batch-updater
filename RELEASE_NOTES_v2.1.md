# Podcast Tag Batch Updater v2.1

## Highlights

- Track Number tags contain one number only, e.g. `11` instead of `11/15`.
- A saved per-show state file preserves numbering after old episodes are removed.
- New episodes can be sorted by natural filename order or file modification time.
- Preview mode and optional source-audio backup help reduce accidental changes.

## Usage

Download and extract the release ZIP, keep the Python script and two `.bat` launchers in the Podcast root folder, create a `podcast.json` in each show folder, and run preview before applying changes.
